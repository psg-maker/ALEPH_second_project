# ALEPH_second_project
SKT ALEPH 2주차 과제 저장소

게임명: 웹 테트리스
가이드라인을 준수하여 자바스크립트를 사용한 테트리스게임 제작

1차테스트: 30초 안에 두줄을 제거하는 것이 어려워보이지만 조금 더 진행해보면서 수정해보기로함, 내려오는 기능에 가속도 있어서 게임을 플레이하는데 있어서는 어려움이나 버그, 에러는 느끼지 못하였으나,
아래 방향키를 꾹 눌렀을때, 누르고 있는 동안 블럭이 쭉 내려갔으면 좋겠다라는 생각을 하여 수정을 진행하였음.

2차 테스트 : 10회 시도 중 미션을 5회 성공한 것으로 확인하였다, 난이도 자체는 어렵지 않다고 판단하였으며
성공은 가능하다고 판단하였고, 미션 해소 후에도, 게임을 계속 진행하고 싶어서 무한 모드로 변경을 하였으며,
미션이 이제 없기 때문에 천장에 닿으면 게임 오버되는 것으로 설정하였음.

3차 테스트: 무한 모드 진입 시, 지울 줄의 목표줄이 1줄로 맞게 설정되어 있는건 확인하였으나,
플레이어가 미션을 완료하고 무한 모드에서 8줄을 지웠다고 가정했을 때
여전히 목표줄은 1줄로 고정되어 있음을 확인하였으며, 8/1 줄이라고 노출되어 있음을 확인함, 무한모드 진입 시, 목표 제거 줄을 없애고 제거된 줄만 노출시키기 위해 수정하였음.

4차 테스트: 게임 내의 블록 종류가 다양하지 못한 것 같아서 조금 더 많은 블록을 추가함. 3차 테스트에서 발생한 버그들과 에러들을 수정하고, 수정된 부분까지 확인하였음.

5차 테스트: 추가 확인된 버그는 없었으며, 다양한 블록을 추가하였을 때, 난이도 자체의 급락이 있었음(gpt 자체 시뮬레이션 10판 결과가 이전보다 현저히 올라간 것이 확인되었음)
추가로 3x2 블록과 3x3 블록을 추가하여 난이도 상승을 기대해볼 수 있겠다라고 생각하여 수정함

6차 테스트: 3x2 블록과 3x3 블록을 추가하여 난이도가 상승된 것이 체감되었으며, 여전히 30초 입문 미션에 대한 부분은 어렵게 만들지 않았음.
추가 확인된 버그는 없으며, 모바일 웹에서도 원활한 진행을 위해 하단 fix controller 를 제안하고, 정상 구동을 확인함. 창 트레이 시, 게임이 자동으로 멈추게 설정되어있음.

7차 테스트: 모바일 조작 키 및 게임 시작 버튼 활성화 확인하였으며 특별한 버그는 발생되지 않았기에 최종본으로 업로드함.
